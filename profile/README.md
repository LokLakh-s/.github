# LokLakh's

Open-source and self-hosted tools, made in France by [Klakh](https://github.com/Klakh).

## Open source

- **[JellyCrowd](https://github.com/LokLakh-s/JellyCrowd)**: one plugin to rule them all for
  Jellyfin. A TMDB catalog, media requests, per-user quotas, branding and stats, right inside
  Jellyfin (AGPL v3).
- **[Klakboard](https://github.com/LokLakh-s/Klakboard)**: a dashboard for the small screen next to
  your monitor. Markets, weather and system load at a glance, on small panels, bar and portrait
  screens (Windows, macOS, Linux; MIT).

  <a href="https://github.com/LokLakh-s/Klakboard"><img src="https://raw.githubusercontent.com/LokLakh-s/Klakboard/main/docs/screenshots/bar-1920x480.png" width="600" alt="Klakboard on a 1920 × 480 bar screen: market badges, weather and system load side by side"></a>
- **[LCDHost Revival](https://github.com/LokLakh-s/LCDHost-Revival)** brings LCDHost, the plugin
  manager for Logitech G15/G19 LCD screens abandoned in 2016, back to life on today's systems (GPL v3).
- **[OffLok](https://github.com/LokLakh-s/OffLok)**: your computer as its own DNS resolver. It finds
  every site's address itself, starting from the root servers, with no internet provider, Google or
  Cloudflare in between; blocking trackers and malicious sites is included, off at first (Windows,
  Linux, macOS coming; MIT). Website: [offlok.org](https://offlok.org).

## Sponsoring

Sponsoring LokLakh's is a voluntary donation: nothing is sold and nothing is owed in return. It pays
for the home server these tools run and are tested on (electricity, internet connection, backups),
and gives more time to develop them.

A monthly sponsorship can be stopped at any time from your GitHub account.
