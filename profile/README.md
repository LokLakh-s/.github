### <img src="https://raw.githubusercontent.com/LokLakh-s/.github/main/profile/img/offlok.png" width="36" height="36" align="absmiddle" alt=""> [OffLok](https://github.com/LokLakh-s/OffLok)

**Your computer as its own DNS resolver.** It looks up every site's address itself, starting from the root servers,
with no internet provider, Google or Cloudflare in between. Blocking trackers and malicious sites is included, off
at first. macOS is on its way.

[![Licence: MIT](https://img.shields.io/badge/licence-MIT-e2ac33?style=flat-square&labelColor=1d1d23)](https://github.com/LokLakh-s/OffLok/blob/main/LICENSE)

[![Download the latest release](https://img.shields.io/badge/download-latest_release-3f8f5a?style=flat-square&labelColor=1d1d23)](https://github.com/LokLakh-s/OffLok/releases/latest)

## Support

Donating is voluntary: nothing is sold and nothing is owed in return. Donations pay for the home server these tools
run and are tested on (electricity, internet connection, backups), and give more time to develop them.

<a href="https://liberapay.com/LokLakh/donate"><img src="https://liberapay.com/assets/widgets/donate.svg" height="30" alt="Donate using Liberapay"></a>

Liberapay itself takes nothing; the payment processor keeps about 3 % by card or SEPA direct debit and 5 % by PayPal,
on average. A recurring donation can be stopped at any time from your Liberapay account.
